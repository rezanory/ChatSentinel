# ChatSentinel Full Project Mode

Canonical activation phrase:

`CHATSENTINEL FULL PROJECT MODE`

Meaning: use the `full` profile from `config/project-profiles.json` for the current project and chat. Create or attach the ChatSentinel project, enable auto-recovery and Chrome tab grouping, preserve session snapshots and selective restore, keep only active parallel chats in the active view, and keep conversation DOM compaction enabled for Chrome memory control.

Use Component-First development. Parallelize only independent lanes. Reconcile Git/local/remote before acting. Maintain canonical handoff and anti-blocker evidence. Use the Integration Controller for serialized union and complete gates without fail-fast. Use a local/self-hosted runner when the project needs one and the authorized device provides it.

Search/export/import and audit/history remain available. Completed or stale chats leave the active parallel view without deleting historical evidence. Do not merge `main`, close release issues, tag Production, or activate a release unless every required acceptance item and independent gate passes.

A project-specific instruction that follows the activation phrase overrides only that explicit detail; the rest of Full Project Mode remains active.

## One-click activation

The ChatSentinel panel includes `Insert Full Project Mode`. It prepends the canonical activation phrase to the current ChatGPT composer without sending the message and without overwriting existing prompt text. Repeated clicks are idempotent and do not duplicate the activation phrase.
